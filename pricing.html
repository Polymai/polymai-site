Requirements

Bring your own AI and provider accounts

Polymai currently runs as a VS Code extension. Run Polymai first to prepare the project and task files, then run the coder you choose. Codex and Claude Code have launch shortcuts; another compatible coding agent can use the copied task. You keep ownership of your AI and provider accounts.

Preferred coders

After Polymai prepares the task, launch Codex or Claude Code for full app builds, review loops, code changes, and complex SaaS workflows.

Other coders

After Polymai prepares the task, run any coding agent that can open the workspace and follow those files. Copy the handoff when no launch shortcut is available.

Experimental

Direct API or Ollama/local model workflows. Useful for simpler or lightweight tasks, but may need more manual review than the preferred coding agents.

Polymai is coder-agnostic: it prepares the project first, then you run your coder. Codex and Claude Code are preferred, but another compatible coding agent can use the same task files.
