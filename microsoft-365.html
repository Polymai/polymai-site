Details for IT and Security

The technical answers.

Open a question for the details. The privacy notice has the full picture.

How is Polymai installed?

Polymai is a SharePoint Framework solution that appears as a Teams app. An administrator adds it from the Microsoft Teams Store or your app catalog, and its code is then served from your own SharePoint. People use it as a personal app or as a channel tab.

Where is data stored?

In your tenant. Projects, app files, records, and uploaded documents are saved in SharePoint lists and libraries created for each app. Some features use a private Polymai folder in the user's OneDrive, and builder preferences stay in the browser.

Which permissions does it use?

Only delegated Microsoft Graph permissions, so Polymai can reach no more than the signed-in person. An administrator approves them once. Mail access is used to create drafts that people send themselves; Polymai never sends email. The full list is in the privacy notice.

How is AI used?

Requests go to Microsoft 365 Copilot through Microsoft Graph, under each user's own licence and your agreement with Microsoft. A request holds the app description, plan, relevant app files, and anything the user chooses to add. Web search runs only if your organisation allows it.

How are generated apps isolated?

Each app runs in a sandboxed frame without network access. It reads and writes data only through Polymai, limited to the lists and Microsoft 365 actions in its approved plan and to the user's own permissions. Outside libraries or map tiles load only if the builder allows them.

Who can see an app?

A new app is private to its owners. Owners add people from the app's own gear, and SharePoint enforces every permission. In a channel, the channel's owners build and its members use the apps, in standard, private, and shared channels.

What if we remove Polymai?

The builder stops running. Apps you have published are separate SharePoint solutions, so they and their records stay in your tenant until you remove them.

Does Polymai collect any data?

No. CarbMind runs no server for Polymai and receives no content, records, or usage data. There is no analytics or advertising. Microsoft processes diagnostic data for Teams and SharePoint under its own terms.
