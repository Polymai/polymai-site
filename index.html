Answers

Common questions, answered plainly.

The short version of what Polymai does, what it creates, and what you need to begin.

What is Polymai?

Polymai is an app-building workflow in VS Code. It turns a plain-language idea into a clear plan and keeps the build easy to preview, review, and improve.

How does it build?

You describe the outcome and Polymai prepares the project. You then run Codex, Claude Code, or another compatible coding agent before returning to Polymai for previews, checks, and later changes.

What can it create?

Polymai is suited for SaaS tools, customer portals, dashboards, internal workflows, admin panels, data-backed apps, and service-connected prototypes.

Which services fit?

It can plan apps with sign-in, saved data, file uploads, payments, email, AI features, scheduled tasks, webhooks, and publishing.

How are secrets handled?

Private service keys stay out of public app files, while sensitive work runs behind server-side or provider-owned boundaries.

What is needed to start?

Bring VS Code, an app idea, and your chosen coding agent. Polymai prepares portable task files first; you then run Codex, Claude Code, or another compatible coder.
